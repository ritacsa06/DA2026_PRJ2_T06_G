Core pipeline orchestrator for register allocation. 

Executes the complete flow of the program:\+
\begin{DoxyEnumerate}
\item Parses configuration (available registers and algorithm type).
\item Parses live ranges, merges them into Webs, and builds the interference graph.
\item Dispatches the appropriate register allocation algorithm (basic, spilling, splitting, or free).
\item Writes the final allocation to the output file strictly following the project spec.
\end{DoxyEnumerate}

{\bfseries{Time Complexity:\+}} Dominated by the allocation algorithm chosen:\+
\begin{DoxyItemize}
\item Basic:\+ O(V\texorpdfstring{$^\wedge$}{\string^}2 + E)
\item Spilling/\+\+Splitting:\+ O(S \texorpdfstring{$\ast$}{*} (V\texorpdfstring{$^\wedge$}{\string^}2 + E)) or O(\+S \texorpdfstring{$\ast$}{*} V\texorpdfstring{$^\wedge$}{\string^}2 \texorpdfstring{$\ast$}{*} L)
\item Free:\+ O(V \texorpdfstring{$\ast$}{*} (V\texorpdfstring{$^\wedge$}{\string^}2 + E))
\end{DoxyItemize}
