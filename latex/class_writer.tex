Static utility class responsible for writing the final allocation result to an output file.

Writes the computed \doxylink{struct_allocation_result}{Allocation\+Result} to the specified file path. 

Iterates through the webs and their assigned registers to construct the final text file. If the allocation was completely unsuccessful according to the strict rules, it formats all webs to memory (\textquotesingle{}M\textquotesingle{}) and sets registers to 0, printing a warning to {\ttfamily std::\+cerr}.
