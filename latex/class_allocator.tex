\doxysubsection{Detailed Description}
Performs register allocation through graph coloring. 

Supports four modes corresponding to the project tasks:\+
\begin{DoxyItemize}
\item T2.\+1 (allocate):\+ Basic greedy simplification + coloring.
\item T2.\+2 (allocate\+With\+Spilling):\+ Coloring with up to K controlled web spills.
\item T2.\+3 (allocate\+With\+Splitting):\+ Coloring with up to K web splits.
\item T2.\+4 (allocate\+Free):\+ Custom heuristic using a Cost-\/\+Benefit metric. 
\end{DoxyItemize}

Divides a web into two at the optimal cut point to minimize resulting interferences. {\bfseries{Time Complexity:\+}} O(\+L \texorpdfstring{$\ast$}{*} V), tests all possible cut points L against all other webs V.
