Detailed Description

Performs register allocation through graph coloring.

Supports four modes corresponding to the project tasks:

  • T2.1 (allocate): Basic greedy simplification + coloring.
  • T2.2 (allocateWithSpilling): Coloring with up to K controlled web spills.
  • T2.3 (allocateWithSplitting): Coloring with up to K web splits.
  • T2.4 (allocateFree): Custom heuristic using a Cost-Benefit metric.

◆ allocate()

AllocationResult Allocator::allocate ( )

Runs the basic greedy graph-coloring register allocation (T2.1).

Executes basic allocation without any controlled spilling or splitting. Time Complexity: O(V^2 + E), where V is the number of webs and E is the number of edges.

Tries to color the interference graph with at most numRegisters_ colors. If the graph cannot be colored without spilling, the allocation is still attempted: spilled webs receive NO_REGISTER and success is set to false.

  • Time Complexity: O(V^2 + E), where V is the number of webs and E is the number of interference edges.
Returns
AllocationResult with the coloring outcome.

◆ allocateFree()

AllocationResult Allocator::allocateFree ( )

Executes the custom Cost-Benefit register allocation algorithm (T2.4).

Executes allocation using the custom Cost-Benefit smart heuristic. Time Complexity: O(V * (V^2 + E)), as it iterates through possible smart spills.

Uses a smart spill candidate selection based on the ratio of the web's effective degree to its size (number of active lines). This minimizes memory access overhead by keeping long-living variables in registers.

  • Time Complexity: O(V * (V^2 + E)) in the worst case, as it may attempt to spill up to V webs.
  • Returns
    AllocationResult with the coloring outcome.

◆ allocateWithSpilling()

AllocationResult Allocator::allocateWithSpilling ( int maxSpills)

Runs register allocation with controlled web spilling (T2.2).

Executes allocation allowing up to maxSpills controlled spills.

First attempts basic coloring with no forced spills. If it fails, iteratively pre-spills the highest-degree web (maximum interference removal per spill) and retries, up to maxSpills times total. Returns as soon as coloring succeeds (minimum spills used).

  • Time Complexity: O(S * (V^2 + E)), where S is maxSpills, V is the number of webs, and E is the number of edges.
Parameters
maxSpillsMaximum number of webs allowed to be pre-spilled.
Returns
AllocationResult with the coloring outcome.

Iteratively removes the web with the highest effective degree and retries coloring. Time Complexity: O(S * (V^2 + E)), where S is maxSpills.

◆ allocateWithSplitting()

AllocationResult Allocator::allocateWithSplitting ( int maxSplits)

Runs register allocation with controlled web splitting (T2.3).

Executes allocation allowing up to maxSplits controlled web splits. Time Complexity: O(S * V^2 * L), where S is maxSplits.

Attempts basic coloring. If it fails, splits the highest-degree web into two derived webs, rebuilds the interference graph, and retries. Repeats until coloring succeeds or maxSplits is exhausted.

  • Time Complexity: O(S * V^2 * L), where S is maxSplits, V is the number of webs, and L is the maximum number of active lines in a web.
  • Parameters
    maxSplitsMaximum number of webs allowed to be split.
    Returns
    AllocationResult with the coloring outcome.

Core coloring engine used by the allocation methods.

Core engine that performs graph simplification and coloring.

Runs the simplification and coloring loop. Webs in forcedSpills are removed from the working graph before simplification begins so they never consume a register slot.

  • Time Complexity: O(V^2 + E), where V is the number of webs and E is the number of edges.
Parameters

AllocationResult with the coloring outcome.

Pushes nodes with degree < K onto a stack. Nodes remaining are spilled. Then pops nodes and assigns the lowest available color. Time Complexity: O(V^2 + E), as it scans vertices and their adjacencies.

Splits a web into two derived webs at the best cut point.

Divides a web into two at the optimal cut point to minimize resulting interferences. Time Complexity: O(L * V), tests all possible cut points L against all other webs V.

Tries every possible cut point (between consecutive active lines) and picks the one that minimises max(degree_left, degree_right) in the current interference graph.
