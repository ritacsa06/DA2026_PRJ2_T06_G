Detailed Description

Static utility class responsible for parsing input files and constructing the foundational data structures.

Handles the extraction of configuration settings and the processing of variable live ranges to build the interference graph used by the allocator.

◆ parseRangesAndBuildGraph()

Graph< Web > Parser::parseRangesAndBuildGraph ( const std::string & filename)
static

Reads the live ranges file, constructs webs, and builds the interference graph (T1.2).

Reads the file line by line. Uses a greedy algorithm to merge overlapping or contiguous live ranges belonging to the same variable into a single unified Web. After assigning definitive IDs, it builds the interference graph by checking execution point overlaps between all pairs of webs using websInterfereGlobal.

  • Time Complexity: O(L + W^2 * P), where L is the number of lines in the file, W is the final number of merged webs, and P is the average number of active program points per web.
  • Parameters
    filenamePath to the live ranges text file.
    Returns
    A Graph<Web> representing the interference graph.
    Exceptions
    std::runtime_errorif the file cannot be opened.
